# my-ai-learning-app

这是一个 AI 学习平台项目。

## 项目目标

我想做一个用于展示深度学习案例的 Web 应用，帮助用户学习 PyTorch、TensorFlow 和 OpenCV 的基础案例。

## 第一版功能

1. 首页：展示项目标题和简介
2. 课程列表页：展示不同学习模块
3. 课程详情页：展示课程介绍、代码示例和学习说明
4. 支持的模块：
   - PyTorch 实战
   - TensorFlow 实战
   - OpenCV 实战
5. 暂时不需要登录
6. 暂时不需要数据库，数据可以先写在本地 JSON 文件中

## 技术要求

请使用 React 创建前端应用。

## 开发要求

1. 先创建一个最小可运行版本
2. 页面简洁清楚
3. 代码结构适合新手学习
4. 添加 README 说明如何启动项目
